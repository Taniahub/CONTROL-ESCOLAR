# CONTROL ESCOLAR

Aplicación web para el control escolar de una institución educativa.

## Módulos
- **Alumnos:** inscripciones, reinscripciones, bajas, cambios de carrera, pagos y evaluación de profesores.
- **Profesores:** CRUD de calificaciones parciales, finales y extraordinarias; reporte de calificaciones y asistencias.
- **Administrativo Nivel A:** CRUD de materias y horarios de profesores y alumnos.
- **Administrativo Nivel B:** CRUD de pagos, becas y titulación.
- **Director de carrera:** CRUD y evaluación de profesores, carreras, planes de estudio y postgrados.
- **Secretario Académico:** reportes de matrícula, bajas y deserciones, becas y aprovechamiento por grupo, carrera y nivel académico (licenciatura y maestría).

## Vista HOME
Menú principal con acceso a cada módulo según el rol del usuario.

## Tecnologías
Laravel, JavaScript, Git y GitHub.
